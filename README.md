# Real-Time Force Regulation for Whole-Hand Dexterous Grasping

Independent simulation reproduction of **Real-Time Force Regulation for Whole-Hand Dexterous Grasping** by Sang Min Kim, Alexander Alexiev, Tzu-Yuan Lin, Sangbae Kim, Young Min Kim, and Yonghyeon Lee. This repository implements geometry-based contact estimation, constrained contact-force allocation, and closed-loop disturbance demos for **MuJoCo with a Robotis HX5-D20 hand** and **DexJoCo with the native bimanual Allegro assembly scene**.

If this work interests you, please read, cite, and support the original authors' work. [Original paper](https://arxiv.org/abs/2609.30082) · [Authors' project page](https://sangminkim-99.github.io/reactive-grasp-whole-hand/)

本仓库复现上述论文的几何接触估计与全手力调节，在 MuJoCo 的 Robotis 手和 DexJoCo 的 Allegro 手上运行。欢迎阅读、引用并支持原论文。

## Install

Linux and Python 3.11 are the tested setup. Headless trials run on CPU. The native viewer needs a graphical session and OpenGL. MuJoCo binaries generated by the preparation step use MuJoCo 3.4.0.

```bash
git clone https://github.com/Wu-didi/Real-Time-Force-Regulation.git
cd Real-Time-Force-Regulation
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install -e .
wholehand --help
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1
```

## MuJoCo with Robotis HX5-D20

Clone the public hand model and run the box scene to check the install. This scene starts from a default hand pose and is a smoke test.

```bash
git clone https://github.com/ROBOTIS-GIT/robotis_hand.git third_party/robotis_hand
git -C third_party/robotis_hand checkout 7730b76bbac51786b122023a7ab2afc17afc7d12
ROBOTIS_XML=third_party/robotis_hand/robotis_hand_description/mujoco/hx5_d20_rev2/hx5_d20_right.xml
wholehand mujoco --robotis-xml "$ROBOTIS_XML" --seconds 0.2
```

For the mustard bottle grasp, download the YCB mesh and build its signed-distance grid and convex collision meshes. Asset preparation can take several minutes. The CPU path uses Warp's CPU backend. A CUDA installation can use `--device cuda:0`.

```bash
python -m pip install -e '.[ycb]'
mkdir -p assets/ycb
curl -fL https://ycb-benchmarks.s3.amazonaws.com/data/google/006_mustard_bottle_google_16k.tgz \
  -o assets/ycb/mustard.tgz
tar -xzf assets/ycb/mustard.tgz -C assets/ycb
MESH=$(find assets/ycb/006_mustard_bottle -name nontextured.stl -print -quit)
wholehand prepare-ycb --mesh "$MESH" --output assets/mustard
wholehand mujoco --robotis-xml "$ROBOTIS_XML" --ycb assets/mustard \
  --grasp examples/mustard-grasp.json --viewer
```

The grasp JSON records 20 Robotis joint angles in radians and the object's position in meters and `wxyz` quaternion. It is one initialization from our simulation. To use a saved simulator state, pass `--state state.npz` with `qpos` and optional `qvel`, `ctrl`, `mocap_pos`, and `mocap_quat` arrays matching the compiled model. For another YCB mesh, prepare a new asset directory and supply a compatible grasp and mass. [Robotis hand](https://github.com/ROBOTIS-GIT/robotis_hand) · [YCB benchmarks](https://www.ycbbenchmarks.com/)

## DexJoCo with Allegro

Install the DexJoCo dependency from the version used for the port. Follow its asset setup instructions if any meshes are missing.

```bash
git clone https://github.com/brave-eai/dexjoco.git third_party/dexjoco
git -C third_party/dexjoco checkout 8d23b0fab23b17a58c4b55f3942e17013aaf8267
python -m pip install -e third_party/dexjoco/dexjoco
```

Use a bimanual assembly episode from the DexJoCo raw data. The capture command accepts a Zarr replay with `data/action` shaped `(T, 46)` and `data/state`, the format produced by the DexJoCo replay converter. Download and convert a bimanual assembly episode using the upstream data conversion instructions. Use the resulting `replay.zarr` path below. [DexJoCo installation and data conversion](https://github.com/brave-eai/dexjoco) · [DexJoCo raw dataset](https://huggingface.co/datasets/DexJoCo/DexJoCo-Datasets-Raw)

```bash
MUJOCO_GL=egl wholehand capture-dexjoco --replay /path/to/replay.zarr \
  --output assets/dex-grasp
wholehand dexjoco --grasp-dir assets/dex-grasp --seconds 2
wholehand dexjoco --grasp-dir assets/dex-grasp --viewer
```

Capture replays the episode and selects the first frame with at least 3 cm of peg lift and contact from at least two finger groups. `READY.json` records whether the criterion was met. If the replay never meets it, capture saves the final frame and reports `qualified: false`. The controller reads `model.mjb`, `initial_state.npz`, and optional `model_changes.npz`. It derives the hand surface samples and object SDF from the compiled model. `--hand-samples` and `--sdf` can load equivalent precomputed assets. `--target socket` selects the left-hand socket and requires a corresponding initial grasp.

## Desktop force controls

| Input | Action |
|---|---|
| Space | Run or pause |
| R | Reset and pause |
| Double-click the object | Select it |
| Ctrl + right mouse drag | Apply force at the picked point |
| Ctrl + left mouse drag | Apply torque |
| 1 or 2 | Apply a 0.5 s pulse on +X or −X |
| 3 or 4 | Apply a 0.5 s pulse on +Y or −Y |
| 5 or 6 | Apply a 0.5 s pulse on +Z or −Z |
| − or = | Halve or double the next pulse amplitude |
| X | Clear the force |

Initial pulse amplitudes are 1 N for Robotis/YCB and 0.05 N for DexJoCo. Axes are in the world frame. [MuJoCo viewer controls](https://mujoco.readthedocs.io/en/3.4.0/programming/samples.html#simulate)

## Headless disturbances and comparisons

```bash
wholehand mujoco --robotis-xml "$ROBOTIS_XML" --ycb assets/mustard \
  --grasp examples/mustard-grasp.json --protocol --rotation 90 \
  --output runs/robotis-whole-hand.json

wholehand dexjoco --grasp-dir assets/dex-grasp --protocol --rotation 90 \
  --method fixed_impedance --output runs/dex-fixed-impedance.json
```

Both controllers sample the hand surface, transform the points by forward kinematics, and query a canonical object SDF with the simulator's object pose. The default keeps up to five candidates per link from the signed 10 mm band, ranked by absolute distance. An OSQP problem allocates forces under friction, torque, normal force, and actuation-consistency constraints. The solver falls back to the last feasible torque. The default torque cap is 0.2 N·m, the friction coefficient is 0.7, and the minimum total normal force is 10 N. The simulation runs with gravity off.

`--protocol` checks grasp retention with a hand hull and object bounding box. It runs one second of settling, six ±XYZ loads at 0.1 times object weight, and, when a rotation is requested, a spring-driven rotation followed by six more loads. JSON includes target and achieved rotation, grasp loss time, QP feasibility, candidate counts, and peak torque. Match initial states, seeds, and timing when comparing `whole_hand`, `fingertip_only`, `fixed_feedforward`, and `fixed_impedance`. The fixed baselines allocate forces once from the initial geometric candidates. `--period` controls the fixed simulation-time update interval.

These trials use public scene assets and locally prepared grasps. The paper's grasp set, exact simulator settings, and reported aggregate rates are outside this release. The regulation controller uses the simulator pose and mesh geometry. DexJoCo replay capture uses simulator contact information to find an initial grasp. Running the controller requires no policy checkpoint, contact training, or vision model.
